# PlanetaryFacts-Group13-project
Capstone project recreating a planet info page from a figma design using HTML, CSS and JavaScript.

## About the Project
The project is a responsive web app that fetches planet data from an API and displays it in a clean card and a comparison table. Users can search for a planet by name and switch between light and dark mode. Built as the TSAcademy front-end capstone project (Hajime Cohort), recreating the provided Figma design.


## Features

- Fetches planet data using the Fetch API (name, image, type, distance from sun, mass, diameter, period, temperature, gravity, moons, description).
- Search bar to find a planet by name.
- Planet card that updates when you search or click a table row.
- Comparison table of planets grouped by type (Terrestrial, Gas Giants, Ice Giants, Dwarf Planets)
- Light and dark mode toggle.
- Responsive layout for desktop, tablet and mobile.
- Semantic HTML and accessible labels.

## How to run the project locally

1. Clone the repository:

   ```bash
   git clone https://github.com/gbemisolaolaniyan2020-ux/PlanetaryFacts-Group13-project.git
   ```

2. Go into the project folder:

   ```bash
   cd PlanetaryFacts-Group13-project
   ```

3. Open `script.js` and set `API_URL` at the top to the planet API address.

4. Open `index.html` in your browser, or use the **Live Server** extension in VS Code:
   Right-click `index.html` → **Open with Live Server**.

   No installation or build step is needed.
